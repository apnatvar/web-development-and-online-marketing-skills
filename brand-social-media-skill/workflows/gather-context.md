# Gather campaign context

## Stage 1: blocking

Confirm product name and factual description, primary audience, campaign objective, primary conversion action, CTA destination, and selected platforms. Stop generation if any of these remain ambiguous enough to materially change the campaign.

## Stage 2: important

Ask focused questions about problem, mechanism, maturity, features, benefits, differentiation, objections, positioning, voice, commercial model, restrictions, available proof, offer terms, publisher identity, timing, and distribution. Ask only the questions needed for the next output.

## Stage 3: optional

Collect secondary audiences, formatting preferences, secondary CTA, publishing frequency, visual preferences, tracking parameters, competitor policy, and measurement preferences when useful.

## Storage

Write answers into the matching file under `context/`; keep authoritative URLs in `context/sources.md` and material assumptions in `strategy/assumptions.md`. Classify proof using `knowledge/claims-and-evidence.md`.

Before using imported content, scan for credentials, personal data, internal URLs, confidential names, and unpublished information. Flag suspected sensitive content instead of moving it into public drafts.
