# DM personalisation notes

Reusable fields:

- `{{first_name}}`: confirmed profile name.
- `{{company}}`: confirmed current organisation.
- `{{role}}`: confirmed current public role.
- `{{observed_problem}}`: explicitly stated problem, not an inference from a job title.
- `{{relevant_trigger}}`: current public event that explains timing.
- `{{specific_reference}}`: exact public source the sender actually reviewed.
- `{{product_value}}`: one supported mechanism relevant to the source.
- `{{cta}}`: one low-friction, channel-appropriate question.

Example source: a clearly fictional public conference note by “Morgan” about decision history. Replace or remove every field before sending. Do not claim familiarity, reading, following, or product use that the source does not establish.
