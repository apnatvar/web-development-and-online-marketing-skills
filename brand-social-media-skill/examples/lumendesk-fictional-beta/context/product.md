# Product

- Name: LumenDesk
- Category: Fictional collaborative research software
- Description: LumenDesk is a fictional workspace that groups notes, questions, and source links around a research decision.
- Main problem: Small teams lose the reasoning behind decisions across scattered documents.
- How it works: A team creates a decision space, attaches sources, and writes a shared conclusion.
- Features: Decision spaces, Source cards, Shared conclusions
- Benefits: Keeps a fictional decision trail together
- Differentiators: Organises work around decisions rather than document folders
- Maturity: beta
- Commercial model: Fictional free beta
- Availability: Fictional global beta
- Restrictions: Fictional data only
- Prerequisites: A modern browser
