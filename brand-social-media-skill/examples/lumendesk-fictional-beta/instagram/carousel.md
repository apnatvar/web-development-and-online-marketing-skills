## Visual direction

Cream background, indigo field labels, one simple line icon per slide, high contrast, and no more than 22 words on a slide. Use an explicitly labelled mockup if product UI is later added.

## Accessibility

Add custom alt text to each slide. Repeat the full method in the caption so the carousel is not the only source of information.
