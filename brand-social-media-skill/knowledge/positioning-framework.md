# Positioning framework

Write the positioning statement as:

> For [specific audience] facing [specific problem], [product] is a [category] that [value]. Unlike [current alternative or category convention], it [supported differentiator]. Evidence: [public-safe proof or explicit limitation].

## Procedure

1. Separate the user, buyer, and influencer when they differ.
2. Name the current alternative, including “do nothing” or an internal process.
3. Define the category in language the audience already understands.
4. Select one primary value, not a list of features.
5. State only defensible differentiation.
6. Match the promise to the available evidence and maturity.

## Messaging pillars

Give each pillar a distinct job:

- Problem insight: explain why the current situation is costly or frustrating.
- Mechanism: show how the product approaches the problem.
- Outcome: state a supported user benefit without guaranteeing it.
- Proof: expose a demonstration, source, case, or limitation.
- Action: make the next step concrete and proportionate.

Reject pillars that are merely synonyms. Record the chosen hierarchy in `strategy/messaging-pillars.md`.
