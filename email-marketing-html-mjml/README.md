# Email Marketing HTML and MJML

## What it does

Writes, designs, personalises, and validates reusable HTML emails for campaigns, newsletters, outreach, lifecycle messages, and transactions. It supports MJML, standard HTML, and optional Emailcn workflows.

## Why use it

Use it to create branded emails that render reliably, remain accessible, support automation fields, and reduce avoidable deliverability or spam problems. See [SKILL.md](SKILL.md) for its operating instructions.
