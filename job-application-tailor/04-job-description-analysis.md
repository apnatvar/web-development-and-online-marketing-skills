# Job Description Analysis

Given a job description, extract:

- company
- role title
- location
- work mode
- years of experience
- must-have skills
- nice-to-have skills
- responsibilities
- domain keywords
- tools
- soft skills
- application instructions
- salary
- deadline
- red flags
- reporting line or seniority signals
- required application materials
- work authorisation, travel, shift, or relocation requirements

Then classify user fit:

- direct match
- adjacent match
- missing
- unclear

Separate explicit requirements from reasonable inferences. Quote or closely paraphrase the evidence for material requirements. Treat years-of-experience ranges and degree requirements as written; do not automatically convert preferences into hard filters.

Base Apply / Maybe / Skip guidance on must-have coverage, transferable evidence, practical constraints, and the user's risk tolerance. Do not present a fit score as a hiring probability.

Do not add missing skills to the CV. Add them only to the gap analysis.
