# Output Formats

For each job optimisation, produce:

## Fit Summary
- Strong matches
- Adjacent matches
- Missing/weak areas
- Recommendation: Apply / Maybe / Skip

## ATS Keyword Coverage
| Keyword | Category | Present in CV | Supported by Profile | Action |
| --- | --- | --- | --- | --- |

## CV Suggestions
- Target title
- Summary
- Skills
- Experience bullets
- Material changes from source
- Confirmation queue

## Guardrail Warnings
- Unsupported claims
- Contradictions
- Confirmation needed

## Cover Note
Short, professional, and adapted to the user's target market and requested tone. Do not assume India unless the user indicates it.

- Company
- Role
- Location
- Work mode
- CV version
- Cover note version
- Next action
