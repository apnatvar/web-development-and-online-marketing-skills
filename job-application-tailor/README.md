# Job Application Tailor

## What it does

Compares a candidate's approved evidence with a job description, then produces role-specific CV suggestions, cover letters, outreach, screening answers, and application checks.

## Why use it

Use it to improve relevance and ATS coverage without inventing qualifications, changing metrics, hiding gaps, or automating submission. See [SKILL.md](SKILL.md) for its operating instructions.
