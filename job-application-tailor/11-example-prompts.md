# Example Prompts

## Intake
Help me build my professional profile for full-stack web developer jobs in India. Start with guided questions and store each answer as a claim until I approve it.

## CV Parse
Parse this CV, extract structured profile data, and show me a review table. Do not approve anything automatically.

## Job Optimisation
Analyse this job description against my approved profile. Generate ATS keywords, fit summary, truthful CV suggestions, and a short cover note. Flag unsupported claims.

## Kanban Update
Create a job card for this role, set status to Saved, and list the next action needed before applying.
