# Review Checklists

Before finalising a CV variant:

- Are all metrics copied exactly from approved sources?
- Are all technologies supported by profile data?
- Are dates consistent?
- Are employer names consistent?
- Are role titles accurate?
- Are unsupported claims removed?
- Are missing skills listed as gaps instead of added to the CV?
- Is the CV concise?
- Does the summary match the target role?
- Is the skills section scannable?
- Is the output suitable for ATS parsing?
- Are substantive edits distinguishable from formatting edits?
- Does the wording preserve ownership, scope, seniority, and causality?
- Are sensitive details included only when needed?
- Are uncertainties and confirmation items visible?

Before finalising a job application package:

- CV generated
- Cover note generated
- Keyword coverage reviewed
- Fit score reviewed
- Missing requirements reviewed
- User has manually chosen whether to apply
- Screening answers use only explicit user information
- Final filenames and requested formats are clear
