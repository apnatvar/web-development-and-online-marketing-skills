# Kanban Workflow

Application statuses:

- Saved
- Tailoring
- Applied
- Interview
- Assignment
- Offer
- Rejected
- Archived

Allowed actions:

- Add job manually
- Paste job description
- Analyse job description
- Generate CV suggestions
- Generate cover note
- Move card between statuses
- Add notes
- Add deadline
- Export application package

Not allowed:

- Auto-submit applications
- Log into job boards
- Apply without user action
