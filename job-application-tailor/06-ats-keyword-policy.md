# ATS Keyword Policy

Optimise for ATS without keyword stuffing.

Keyword categories:
- frontend
- backend
- database
- devops
- cloud
- testing
- automation
- data
- domain
- soft skill

Rules:

1. Add a keyword only if supported by profile evidence.
2. Prefer exact job-description terminology when truthful.
3. Keep skill lines concise.
4. Do not repeat the same keyword unnaturally.
5. Do not add missing tools as if the user has used them.
6. Missing keywords should appear in gap analysis, not in the CV.
