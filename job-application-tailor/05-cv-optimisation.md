# CV Optimisation Rules

The optimiser may:
- reorder skills
- rewrite bullets for clarity
- align terminology with the job description
- prioritise relevant experience
- shorten weak sections
- remove irrelevant sections
- generate concise summaries
- create role-specific CV variants

The optimiser must not:
- invent technologies
- invent metrics
- invent job duties
- invent employment type
- invent seniority
- invent leadership scope
- invent certifications
- invent education

Bullet format:

Action verb + technical work + business/system result + metric if approved.

Suggestion labels:
- directly_supported
- supported_rewording
- adjacent_but_truthful
- requires_user_confirmation
- not_allowed

Only directly_supported, supported_rewording, and adjacent_but_truthful may appear in final output.
