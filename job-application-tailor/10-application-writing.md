# Application Writing

## Cover letters and notes

Build the draft from approved evidence rather than generic enthusiasm:

1. Name the role and give a specific reason for interest supported by the job description or user context.
2. Select two or three requirements with the strongest evidence.
3. Connect each requirement to a concise example without adding scope or impact.
4. Address a material gap only when useful, using honest transferable evidence or a learning plan.
5. End with a direct, low-pressure call to discuss fit.

Match the requested locale and tone. Default to a concise professional style. Avoid clichés, exaggerated praise, copied company slogans, and claims about culture that have not been established.

## Recruiter and referral outreach

Keep messages short and easy to answer. Include the target role, one credible fit signal, and a clear request. Do not imply a prior relationship, referral, or shared connection unless the user confirms it.

## Screening questions

Answer only from approved evidence. Respect requested length and format. For salary, work authorisation, relocation, notice period, availability, disability, demographic, or background questions, use only the user's explicit answer; otherwise leave a clearly marked placeholder or ask for confirmation.

Never draft deceptive responses intended to bypass eligibility or screening requirements.
