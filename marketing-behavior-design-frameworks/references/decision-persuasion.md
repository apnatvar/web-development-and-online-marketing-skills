# Decision Science and Persuasion

Behavioural effects are context-dependent. Use them to generate hypotheses and risk checks, not to assert that wording will force a response.

## Persuasion models

| Model | Practical use | Misuse to avoid |
| --- | --- | --- |
| Elaboration Likelihood Model | provide strong arguments for involved readers and clear credibility cues for limited-attention contexts | replacing evidence with surface cues |
| Theory of Planned Behavior | inspect attitudes, perceived norms, and perceived control | assuming intention guarantees behaviour |
| Cialdini principles | review reciprocity, commitment, social proof, authority, liking, scarcity, and unity | fabricated proof, obligation, or scarcity |
| Source credibility | establish relevant expertise, trustworthiness, and transparent interests | vague badges or borrowed authority |
| Narrative transportation | make a situation and consequences concrete through story | presenting a composite story as a real case |
| Reactance Theory | preserve agency and avoid controlling language | disguising pressure as choice |
| Inoculation Theory | state a plausible objection or weak counterclaim and answer it with evidence | caricaturing critics |
| Protection Motivation Theory | pair credible risk with effective, achievable protection | fear without efficacy |
| Rhetorical triangle | balance ethos, pathos, and logos | emotion used to conceal weak evidence |

## Behavioural-economics lenses

| Effect | Responsible application |
| --- | --- |
| Prospect Theory and reference dependence | explain gains, losses, risk, and comparison points accurately |
| Framing effect | test clear alternative presentations without omitting material facts |
| Anchoring | provide relevant, substantiated reference prices or quantities |
| Default and status quo effects | use beneficial, disclosed, reversible defaults |
| Present bias / hyperbolic discounting | make near-term value and immediate effort visible |
| Mental accounting | show total cost, timing, and budget implications clearly |
| Endowment effect | let people experience or configure value without obstructing exit |
| Choice overload | group options and add decision aids; do not assume fewer is always better |
| Decoy / compromise effects | audit plan architecture for distorted comparisons; do not construct deceptive tiers |
| Ambiguity aversion | state process, limits, uncertainty, and terms clearly |
| Availability and representativeness | pair stories with typical outcomes or base-rate context |
| Confirmation bias | address existing assumptions and credible counterevidence |
| Social proof / descriptive norms | use current, representative, verifiable evidence |
| Scarcity and urgency | communicate only real capacity, inventory, or deadlines |
| Peak-end rule | improve the full journey, then ensure critical moments and endings are clear |
| Serial-position / isolation effects | place and emphasise key information without hiding alternatives |
| Bounded rationality / satisficing | make essential comparisons and next steps easy to find |
| Sunk-cost effect | never pressure continuation because of prior time or spending |

## Ethical decision test

Reject or redesign an intervention when any answer is no:

1. Is the claim and proof truthful?
2. Is material information visible before commitment?
3. Can the user refuse, change, cancel, or leave without unreasonable friction?
4. Is any default aligned with the user's likely interest and clearly disclosed?
5. Are urgency, scarcity, popularity, authority, and testimonials genuine?
6. Would the approach remain acceptable if its mechanism were explained to the user?
7. Are vulnerable audiences and asymmetric consequences considered?

Run a **sludge audit** on forms, consent, subscriptions, checkout, cancellation, privacy, and support. Remove friction that benefits only the organisation.
