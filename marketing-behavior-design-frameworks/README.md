# Marketing, Behavior, and Design Frameworks

## What it does

Helps an agent select and apply suitable marketing, customer-needs, positioning, motivation, behavioural-economics, copywriting, content, storytelling, UX, website, and app-design frameworks.

## Why use it

Use it when work needs an explicit analytical basis rather than a light checklist. It distinguishes research-backed theories, professional methods, and practitioner heuristics; connects each framework to evidence and decisions; and blocks deceptive applications.
