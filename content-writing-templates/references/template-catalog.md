# Template catalog

Use `/templates` to discover templates without reading research. IDs are stable machine identifiers; display names may change. The registry in `assets/templates/index.json` contains metadata only. Retrieve a single JSON file by exact ID with the lookup script.

| ID | Name | Objective | Intended use |
| --- | --- | --- | --- |
| `instagram.educational.howto` | Practical how-to | educational | Explain a repeatable task |
| `instagram.educational.checklist` | Ready-to-use checklist | educational | Help readers inspect their own process |
| `linkedin.analytical.insight` | Evidence-led insight | analytical, educational | Explain a useful professional finding |
| `linkedin.narrative.lesson` | Lesson from a process | narrative, educational | Share a process lesson without invented personal stories |
| `x.humorous.observation` | Subtle everyday observation | humorous | Make a relatable process observation |
| `x.educational.thread` | Stepwise explanation thread | educational | Repurpose a guide into a short learning sequence |
| `blog.educational.tutorial` | Task-focused tutorial | educational | Document a process readers can complete |
| `blog.analytical.comparison` | Criteria-led comparison | analytical, educational | Help readers choose between options |
| `email.promotional.aida` | Single-offer email | promotional | Present a supported offer to an appropriate audience |
| `email.educational.digest` | Useful learning digest | educational | Share an insight with an existing readership |

Filter fields: platform, format, objective, tone, framework, length, audience, ID. Length is an editorial category (short, medium, long), not a platform limit. Tones and audiences describe default suitability, not restrictions on customization.
