# Reference analysis and rights

## Evidence capture

For each reference, capture only what is needed to reproduce the editing language:

| Field | Record |
| --- | --- |
| Source | Public URL or authorized local file |
| Context | Account, visible date, platform, format |
| Structure | Hook, escalation, payoff, CTA |
| Timing | Shot and text change timecodes |
| Motion | Direction, easing, scale, rotation, blur |
| Transition | Incoming/outgoing layers and duration |
| Type | Font class, hierarchy, placement, treatment |
| Audio | Beat, lyric, impact, or silence cue |
| Confidence | Observed, inferred, or unavailable |

Use a timecoded beat sheet rather than vague prose. Sample at cuts and transition midpoints when frame-level inspection is possible.

## Rights and fidelity boundaries

- Recreate timing, pacing, layout principles, and generic techniques; do not redistribute the source video.
- Use user-owned, licensed, public-domain, or generated replacement media.
- Do not copy competitor logos, watermarks, distinctive characters, or proprietary footage into the deliverable without authorization.
- Avoid representing the result as official content from the referenced account.
- If the user requests an exact clone, preserve the functional editing grammar while changing protected expressive elements.
- Keep source links and analysis notes separate from render assets.

## Trend shortlist scoring

Score candidates from 1 to 5 on brand relevance, freshness, repeatability with user clips, hook clarity, production feasibility, and differentiation potential. Recommend the strongest reusable pattern, not merely the post with the largest visible engagement count.
