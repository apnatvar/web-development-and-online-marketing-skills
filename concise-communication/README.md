# Concise Communication

## What it does

Shortens agent communication while preserving meaning. It removes filler, limits unnecessary adjectives, and improves sentence structure without leaking editing instructions into reader-facing material.

## Why use it

Use it when responses need to be faster to read and cheaper in tokens without becoming vague, abrupt, or incomplete. See [SKILL.md](SKILL.md) for its operating instructions.
