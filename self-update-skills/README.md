# Self-Update Skills

## What it does

Checks existing skills against authoritative updates, observed failures, and changed workflows, then proposes narrow revisions before making them.

## Why use it

Use it to keep skills current without allowing silent edits, weak-model rewrites, broken workflows, or changes that cannot be reviewed and rolled back. See [SKILL.md](SKILL.md) for its operating instructions.
