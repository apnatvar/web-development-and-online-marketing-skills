# Existing Page Audit

[Back to index](../index.md)

- [ ] State the page's intended audience, query/need, and conversion action.
- [ ] Inspect source, shared layout, data sources, metadata, JSON-LD, sitemap, robots, internal links, and tests.
- [ ] Inspect rendered HTML—not just React source—for title, canonical, robots, one H1, meaningful text, and valid JSON-LD.
- [ ] Confirm title/description/H1 agree without being mechanically identical.
- [ ] Confirm index/noindex, canonical, sitemap inclusion, and internal-link treatment agree.
- [ ] Check that every schema claim is visible and verified; normalize duplicate entity IDs.
- [ ] Check whether the page is genuinely distinct from nearby company, service, product, article, FAQ, or course pages.
- [ ] Locate client boundaries, third-party scripts, imports, media, animation, and bulk link lists.
- [ ] Measure or identify a reproducible problem before changing performance architecture.
- [ ] Check keyboard access, focus, landmarks, labels, reduced motion, and responsive behavior.
- [ ] Compare history when an apparently odd choice may be deliberate.
- [ ] Make the smallest coherent change and add a regression test.
- [ ] Run the validation stack appropriate to the risk and report remaining uncertainty.
