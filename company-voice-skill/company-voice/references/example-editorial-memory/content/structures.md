# Post Structures

## Technical Breakdown

Use when explaining how an implementation decision works.

1. Name the workflow problem.
2. Explain why the obvious solution is incomplete.
3. Break down the operational constraints.
4. Show what a practical version requires.
5. Close with a measured next step.

Do not use this structure for announcements or light observations.
