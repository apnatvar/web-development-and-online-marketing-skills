# Technical Depth

Founder-facing content should explain technical constraints without assuming engineering fluency.

Useful technical detail includes data boundaries, integration points, error handling, model limitations, security review, cost, and maintenance ownership.

Avoid internal implementation jargon unless it is immediately explained.
