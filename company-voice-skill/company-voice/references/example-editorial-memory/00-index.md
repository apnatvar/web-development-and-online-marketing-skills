# Editorial Voice Memory Index

Purpose: compact example memory for a fictional AI implementation consultancy.

Load this file first. Then load only the subdirectory index needed for the task.

## Directory Map

- `identity/`: what the organization is and why it exists.
- `positioning/`: market position, alternatives, and desired perception.
- `audience/`: audience segments and their content needs.
- `strategy/`: business goals, editorial goals, and search visibility.
- `voice/`: primary voice, tone range, and personality behavior.
- `style/`: sentence style, vocabulary, and prohibited language.
- `rules/`: evidence, technical depth, opinion, storytelling, promotion, and CTAs.
- `content/`: pillars, structures, backlog, campaigns, and publishing log.
- `references/`: products, services, pages, resources, and proof points.
- `channels/`: channel-specific behavior.
- `metrics/`: success metrics and performance notes.
- `relations/`: semantic links between decisions.
- `decisions/`: unresolved questions and change history.

Validation: run `company-voice/scripts/validate_editorial_memory.py references/example-editorial-memory` from the repository root.
