# Principle selection

Select the smallest useful set—normally one primary principle family and up to two supporting families.

| Diagnostic signal | Primary reference | Common support |
|---|---|---|
| Customer pain is assumed | [Customer discovery](../references/customer-discovery.md) | Diagnostic selling |
| Reader resists or feels pressured | [Negotiation](../references/negotiation.md) | Narrative |
| Offer is hard to categorize | [Positioning](../references/positioning.md) | Differentiation |
| Features lack situational value | [Differentiation](../references/differentiation.md) | Positioning |
| Idea is abstract or forgettable | [Memorable ideas](../references/memorable-ideas.md) | Narrative |
| Brand is the hero | [Narrative](../references/narrative.md) | Memorable ideas |
| Logic is buried or overlapping | [Structured communication](../references/structured-communication.md) | Strategy |
| Sales copy pitches too early | [Diagnostic selling](../references/diagnostic-selling.md) | Negotiation |
| Message mismatches readiness | [Market awareness](../references/market-awareness.md) | Diagnostic selling |
| Brief has scattered goals | [Strategy](../references/strategy.md) | Structured communication |

## Internal selection note

Record privately:

- diagnosis;
- primary principle and reason;
- supporting principle and reason;
- copy decisions each principle changes;
- principle deliberately omitted.

Do not expose this note or book names unless the user requests rationale, education, or framework attribution. If asked, explain decisions in plain language before naming sources.

Avoid framework stacking. A framework that does not change a claim, order, example, proof choice, or CTA is unnecessary.
