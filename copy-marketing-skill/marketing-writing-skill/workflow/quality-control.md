# Quality control

Score each item `pass`, `revise`, or `unknown`. Revise material failures; disclose consequential unknowns.

| Check | Pass condition |
|---|---|
| Audience clarity | A specific reader can recognize relevance quickly |
| Problem relevance | The copy addresses a supported, consequential issue |
| Positioning | The audience can place the offer in a useful frame |
| Differentiation | Contrast rests on meaningful capability or fit |
| Logical structure | Main point and support form a clear hierarchy |
| Specificity | Important abstractions are made concrete |
| Credibility | Claim strength does not exceed proof |
| Memorability | One useful idea, contrast, or example is retellable |
| Emotional relevance | Stakes are human and proportionate, not theatrical |
| Platform fit | Structure and conventions are native to the channel |
| CTA quality | Action is clear, valuable, and readiness-appropriate |
| Factual integrity | No invented pain, metric, testimonial, feature, or urgency |
| Repetition | Repetition is purposeful, not filler |
| AI phrasing | Canned transitions, hype, and formulaic cadence are removed |
| Reader-facing boundary | Every line belongs to the intended reader; no prompt, instruction, reasoning, workflow, approval, validation, or superior-facing commentary remains |

## Final integrity scan

Search mentally for exact numbers, comparative claims, customer quotations, named integrations, compliance assertions, guarantees, deadlines, scarcity, and performance promises. Trace each to user-supplied or verified evidence. Qualify, remove, or flag anything unsupported.

For multi-platform delivery, compare every output against the [central-idea card](central-idea.md). Adaptation is not permission to strengthen a promise.

## Publication-boundary scan

Read the content alone, without the surrounding conversation. For each line, ask whether a human author would deliberately publish it to the intended reader. If it instead explains the assignment, reports progress, justifies a choice to a superior, instructs an editor, addresses the user, or reveals agent workflow, remove it from the content.
