# Readability guidance

Load only for copy or combined audits.

- Use readability formulas as review triggers, not quality scores or ranking rules.
- Prefer short front-loaded paragraphs, descriptive subheadings, lists for comparable items, and familiar terms where accuracy permits.
- Explain unavoidable specialist language for the stated audience.
- Remove repetition that does not add evidence, detail, or navigation value.
- Judge tone against the stated brand preference without sacrificing clarity or truth.
- Check the actual mobile layout; readable source text can become hard to scan in an oversized hero, narrow column, or broken responsive design.
