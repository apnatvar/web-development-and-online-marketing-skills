# CTA principles

Load only for copy or combined audits.

- Match the primary CTA to the stated desired visitor action.
- Use an action verb and preview what follows: “Book a 20-minute call” is clearer than “Submit.”
- Keep one primary action consistent; distinguish genuinely different secondary actions.
- Place the CTA after enough information for the commitment level, and repeat it where long pages justify it.
- Verify destination, keyboard access, accessible name, loading behavior, mobile visibility, and layout stability.
- Never use fabricated scarcity, urgency, results, or guarantees.
