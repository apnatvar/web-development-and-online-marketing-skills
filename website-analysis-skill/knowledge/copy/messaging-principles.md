# Messaging principles

Load only for copy or combined audits.

Compare visible copy with the user-supplied intent. Review whether a first-time visitor can identify:

1. what the site offers;
2. who it is for;
3. which problem it addresses;
4. why this option is distinct;
5. what to do next.

Prefer concrete nouns and verbs over broad promotional claims. Keep the search-result promise, hero, section sequence, offer details, objections, evidence, and CTA coherent across pages.

Treat missing proof as a request for evidence, never permission to invent it. Do not create customer results, testimonials, statistics, certifications, capabilities, locations, or guarantees.
