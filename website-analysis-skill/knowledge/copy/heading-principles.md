# Heading principles

Load only for copy or combined audits.

- Make the primary visible heading name the page’s main promise or subject.
- Use the subtitle to clarify audience, problem, mechanism, or outcome rather than repeat the heading.
- Order sections around visitor questions: relevance, offer, how it works, evidence, fit/objections, action. Adjust for the page’s actual intent.
- Use semantic levels that reflect nesting; do not choose an element for font size.
- Keep headings specific enough to understand out of context.
- In combined audits, repair words and markup together.
