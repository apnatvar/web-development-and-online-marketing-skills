# Metadata audit guidance

Load only for technical or combined audits.

Check rendered output and, for local repositories, the framework metadata source:

- one useful document title;
- an accurate description candidate;
- intended robots directives;
- one consistent canonical when canonicalization is needed;
- viewport and document language;
- social metadata only when sharing quality is in scope;
- locale alternates only for real alternate pages.

Treat fixed title/description character counts as review heuristics. Check uniqueness, accuracy, query/page intent, and consistency with the visible primary heading. Search engines can rewrite title links and snippets.
