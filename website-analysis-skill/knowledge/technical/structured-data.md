# Structured-data audit guidance

Load only for technical or combined audits when structured data exists or is relevant.

1. Parse JSON-LD/Microdata/RDFa syntax.
2. Confirm that the entity and claims are visible and truthful on the page.
3. Check the most specific applicable schema.org type.
4. Check current Google documentation for the intended rich-result feature and required properties.
5. Validate the deployed page; syntax success does not prove eligibility or appearance.

Never manufacture reviews, ratings, prices, availability, organization facts, author credentials, locations, or certifications. Absence of structured data is not automatically an issue.
