# Gather website intent

Required for copy and combined modes. Collect all fields before analysis:

1. Website purpose.
2. Primary audience.
3. Primary visitor problem.
4. Desired visitor action.
5. Primary product or service.
6. Key differentiator.
7. Geographic or industry focus.
8. Priority pages.
9. Target keywords, if known; use an empty list when unknown.
10. Preferred brand tone.

Save as JSON matching `schemas/website-intent.schema.json`. Ask for clarification when a required answer is blank or contradictory. Treat answers as intended positioning, not proof of claims. Do not add intent that the user did not supply.
