# Run a combined audit

Require complete intent. Run the technical and copy modules on the same approved page set, then follow `combine-findings.md`.

Look specifically for interactions:

- essential copy absent from initial/rendered HTML;
- visually prominent text using incorrect heading semantics;
- weak titles that harm search presentation and message clarity;
- large hero/media delaying meaningful copy;
- CTAs loading late, moving, or failing on mobile;
- repetition affecting both experience and topic quality;
- mobile layout obscuring comprehension;
- missing/broken internal links weakening navigation and discovery.

The final plan must rank one set of repairs by shared impact, dependency, confidence, and effort.
