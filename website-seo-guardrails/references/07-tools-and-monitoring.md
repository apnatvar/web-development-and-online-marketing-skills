# Tools and Monitoring

## Google Search Console

Verify a Domain property and retain access across deployments. Submit sitemaps; inspect important templates; monitor Pages/Indexing, Performance, Core Web Vitals, HTTPS, rich-result enhancements, Manual Actions, Security Issues, removals, messages, and crawl statistics. Segment performance by page family, query intent, country, device, and change cohort. A successful live inspection does not guarantee indexing or ranking.

## Bing Webmaster Tools

Verify/import the site, submit sitemaps, inspect live and indexed URLs, review Site Explorer folders, crawl issues, robots, markup, backlinks, keyword/search performance, malware, and IndexNow insights. Use its folder-level index/excluded/error patterns to spot template-wide problems.

## IndexNow

Use IndexNow to notify participating engines when canonical URLs are added, materially updated, or deleted. Host and protect the 8–128 character key, submit only owned-host URLs, automate from publish/delete events, deduplicate, and limit a POST to 10,000 URLs. A successful response confirms receipt, not crawl, index, or ranking. Do not submit every URL repeatedly or send parameter/staging/noncanonical URLs.

## Ahrefs

Use Ahrefs Free/Webmaster Tools or paid tools for Site Audit, Site Explorer, backlinks, organic keywords/pages, broken links, competitors, content opportunities, and monitoring. Prioritize issues by evidence and impact; do not blindly chase Health Score, Domain Rating, volume, difficulty, or estimated traffic. Investigate lost links, link quality, orphan pages, redirect targets with backlinks, internal links, and content decay.

## Analytics and logs

Connect organic landing pages to engagement, leads, revenue, retention, or learning outcomes. Annotate releases. Use server/CDN logs to confirm crawler access, status patterns, waste, and recrawl. Respect privacy/consent and filter internal/bot traffic appropriately.

## Monitoring cadence

- Immediate alerts: uptime, DNS/TLS, robots/noindex/canonical changes, sitemap failures, 5xx spikes, security/manual-action messages.
- Weekly: index coverage changes, important URL inspections, organic anomalies, crawl errors, conversions, new/lost backlinks.
- Monthly: page-family cohorts, query/intent changes, content decay, Core Web Vitals field data, competitor/market changes, technical crawl.
- Quarterly: policy review, content inventory/pruning decisions, schema support, migration/redirect integrity, access/ownership audit.

Keep a baseline and thresholds appropriate to site size. Seasonality, reporting delay, SERP changes, and migrations can mimic SEO defects; investigate before attributing causality.
