# Website SEO Guardrails

## What it does

Plans, audits, writes, and validates website SEO across crawling, indexing, content, metadata, structured data, Lighthouse, search tools, analytics, and spam policies.

## Why use it

Use it to catch high-impact SEO risks before pursuing traffic, including thin pages, unsafe scaling, misleading markup, indexing mistakes, weak measurement, and recommendations that only sound productive. See [SKILL.md](SKILL.md) for its operating instructions.
